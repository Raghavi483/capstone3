## 1. Project Overview & Architectural Vision
MediCard is an enterprise-grade digital cashless hospitalization and settlement orchestration platform. It connects policyholders, network hospital desks, and health insurance adjudicators to facilitate real-time eligibility lookups, rule-based pre-authorization decisions, automated procedure/admission tracking, and mathematically capped settlement payouts.

### Non-Negotiable Core Rules:
1. **Rule 1 — No-Hand-Coding**: 100% of production code, tests, and migrations are generated by Claude Code agents.
2. **Rule 2 — Spec is Source of Truth**: Specifications always override code (`specs/` is the single source of truth).
3. **Rule 3 — PR-Driven Development**: Zero direct pushes to `main`. All changes flow through feature branches and non-fast-forward merges (`git merge --no-ff`).
4. **Rule 4 — Synthetic Data Only**: Strictly synthetic, dummy seed data.

## 2. Quick Start & Execution

### Prerequisites
- Python 3.12+
- Node.js v20+ / npm 10+
- Git

### Single-Command Local Run (Backend + Seed Data + UI)
```bash
python scripts/run_feature_agent.py --ac AC-07 --spec specs/settlement_spec.md --agent settlement-agent --dry-run
```

### Running Validation Hooks & Test Suite
```bash
# Run guardrail hooks
powershell .claude/hooks/phi-redaction-check.ps1

powershell .claude/hooks/role-boundary-check.ps1
```
